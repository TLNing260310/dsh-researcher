> 角色:Principal Architect。任务不是增加功能,先判断 v0.8-alpha 是否值得开始。
> 审阅输入:README(228 行)、roadmap.md、evaluation/ 全部、docs/principal-decision-v0.7.1.md、docs/principal-verdict-v0.7.1.md、researcher/plugins/research-state/index.js、Experiment A 结果与实证(12 会话日志折叠:137 claims / 89 dependsOn / invalidate=0 / importState=0)。

## Part 1 — research-state 是否具备成为 cognition-state 的条件?

**结论:具备"引擎条件",不具备"结构条件"—— 四项检查中 1 项通过、1 项部分、2 项失败。**

| 条件 | 现状(代码 + 实证) | 判定 | 差距 |
|---|---|---|---|
| **claim 关系** | claim 是扁平条目(id/statement/tier/verdict/evidence[]/confidence),claim 之间无 relation;依赖图存在于 hypothesis/views 层(89 dependsOn 边实证存在) | ❌ 失败 | claim 层无关系;依赖图未下沉到 claim 层 |
| **evidence fingerprint** | evidence 是叙述文本("command.js:953-961"、"lib/command.js full read"),无 blob 指纹,无结构化锚 | ❌ 失败 | 无法机械对账过期;Cognition Diff 前提缺失 |
| **freshness** | 无任何 freshness 字段/机制;无"这条 claim 基于哪个代码版本"的记录 | ❌ 失败 | 无法判断 claim 是否过期 |
| **consumer** | 唯一消费者是模型自己(报告附录);无机器消费方;importState=0(跨会话从未使用) | ⚠️ 部分 | 机制存在(export/importState)但从未端到端验证 |

**引擎条件(通过的部分)**:单 reducer 事件溯源(执行 == 重放,代码正确)、局部失效 + 版本化假设(代码正确,但 invalidate=0 从未触发)、零写契约。这些是"状态机引擎",合格。

**核心判断**:research-state 是**合格的引擎 + 不合格的数据模型**。cognition-state 需要的是"可对账、可查询、可交接的知识表示";当前表示是"供人读的叙述文本"。**从"引擎"到"认知状态"的跨越 = 结构化导出(Part 2),不是改引擎。** 因此 v0.8-alpha 的前提(在不动 Researcher 的前提下补结构)成立。

## Part 2 — 最小 Cognition State Export 设计

> 要求:只是格式转换,不改变 agent。零新工具、零 prompt 修改、零 pipeline 改动。

### 2.1 定义

`cognition-state.json`(schema `dsh-researcher/cognition-state/v1`),由 **host-plane 导出器**从会话日志的 research_checkpoint 事件折叠生成。导出器复用 research-state 的 `foldCheckpointEvents`(纯函数,已存在),**只做格式转换**:

```
session.events.json (tool/call research_checkpoint)
        │  foldCheckpointEvents (现有纯函数,零改动)
        ▼
内部 state (claims/hypotheses/views/dirty)
        │  导出器(新增 host 脚本,非 agent 工具)
        ▼
cognition-state.json (schema v1)
```

### 2.2 Schema(最小,只含已存在字段 + 机械可计算增强)

```json
{
  "schema": "dsh-researcher/cognition-state/v1",
  "run": "#N",
  "project": "commander.js@bf35c5f",
  "generated_at": "...",
  "claims": [{
    "id": "C07",
    "statement": "...",
    "tier": "C2", "verdict": "Known", "confidence": 0.9, "revision": 3,
    "evidence": ["command.js:953-961"],
    "evidence_fingerprints": ["<blob-sha256-of-command.js@953-961>"]
  }],
  "hypotheses": [{"id": "H2", "status": "active", "dependsOn": ["C07"], "revision": 1}],
  "views": [{"name": "project_model", "dependsOn": ["H1", "H2"], "revision": 2}],
  "dirty": [],
  "origin": {
    "session_log": "evaluation/runs/commander.js/exp-a/.../session.events.json",
    "fold_replayable": true
  }
}
```

### 2.3 关键设计决策

1. **只加一个字段**:`evidence_fingerprints` —— 对每条 evidence 锚(形如 `file:line`)解析出文件,取 git blob sha256。这是唯一新增计算,且是 host 侧机械计算(不改 agent、不改 state 插件)。
2. **不新增任何 agent 字段**:claims/hypotheses/views/dirty 全部来自现有状态,逐字段搬运。
3. **可重放性保证**:`fold_replayable: true` = 导出器用同一 reducer 折叠两次结果一致(doctor Replay 检查同构)。
4. **零写契约不变**:导出器是 evaluator/host 脚本,运行在评估目录,不碰项目文件系统、不碰 Researcher 会话。

### 2.4 验收标准(最小)

- 对 Experiment A 的 12 个归档会话日志:导出器全部成功,`fold_replayable: true`;
- 与人工 ledger(从报告 Appendix A 提取)对比:claim 集合一致(同一会话);
- 指纹计算可复现(同文件同 blob 同哈希);
- **导出器不注册任何工具、不注入任何 prompt**。

## Part 3 — Cognition Diff 实验设计(必须能证明 stateful > stateless)

> 实验目标:证明"携带认知状态"优于"从零开始"。这是 H2 的裁决实验。**若不能证明 stateful > stateless,则认知层核心假设失败。**

### 3.1 实验结构(最小)

复用 commander.js 冻结快照 + mutation manifest(6 项,已机械化生成,零新增):

- **T0**:冻结快照 bf35c5f,统一任务(protocol v1.1 §3),建立认知。产出:PCR + checkpoint export(经 export 调用)。
- **T1**:在 T0 快照上注入 1 个 mutation(从 6 项种子化抽取,注入 squash 进截断点,git 历史不暴露注入 —— 上一轮审查修正),盲截断。
- **两种 run-2 条件(同 T1 快照,同任务 = 统一前缀 + 冻结附加句)**:
  - **stateful(Researcher)**:run-2 会话开始时,evaluator 经 `research_checkpoint importState` 注入 T0 的 export(现有机制,零新能力)。
  - **stateless(Researcher 对照)**:run-2 无任何状态输入,从零开始。
  - 基线(Standard/Plan):只跑 stateless(无 claims 机制)。
- **重复**:每条件 × 3 runs;mutation 每条件独立(或跨 run 轮换 2–3 个 mutation 增加稳健性)。

### 3.2 判定指标(机械优先)

| 指标 | 定义 | 真值来源 |
|---|---|---|
| **Stale Recovery**(主) | run-2 正确失效/修正的、被注入直接命中的 T0 claim 比例 | **Cognition Diff 机械判定**(blob 指纹变化 → 应失效集合),不依赖 evaluator 主观 |
| **Mutation Recall** | run-2 检出的注入变化 / 注入清单 | 注入清单本身 |
| **Consistency Drift** | 未变化区域:run-2 与 T0 认知的矛盾率 | Cognition Diff 的 unchanged 集合 |
| **Rebuild Cost Ratio** | stateful 累计 billed tokens / stateless 累计 | 用量事件 |

### 3.3 判定规则(预注册,防事后挑选)

- **stateful > stateless 成立** iff:Stale Recovery(stateful)≥ stateless 对应值 **且** Rebuild Cost Ratio ≤ 1.0(不更贵)**且** Consistency Drift 不劣于 stateless。
- **部分成立**:Stale Recovery 更高但成本 >1.0× → "更准但更贵",报告如实,不视为成立。
- **不成立**:Stale Recovery 无差异或更低,或成本劣势无补偿。

### 3.4 为什么这个实验能证明"不可替代"(而非能力)

- stateless 条件 = 模型原生能力(单次会话理解 + 变化检测)—— 这是"AI 模型进步"的对照组。
- stateful 条件 = 认知层机制(状态继承 + 失效传播)—— 这是 Irreplaceable 假设的正面检验。
- **差值(stateful − stateless)直接量化认知结构的增量价值**;若差值为零或负,则认知结构无增量,核心假设失败,无论 stateless 本身多强(那只是模型能力)。

## Part 4 — 失败标准(明确删除什么方向)

| 结果 | 判定 | 必须删除的方向 |
|---|---|---|
| Stale Recovery 无差异 + 成本无优势 | **H2 失败:认知状态无增量** | **删除**:research-state 图机制(依赖图/失效传播/版本化)作为产品价值、Memory Bridge(v0.9)、Claim Delta、Cognition Handoff 产品化。**保留**:证据纪律、只读边界、PCR 作为"高质量只读分析模式" |
| Stale Recovery 更高但成本 >1.5× | H2 部分失败:更准但不可负担 | **删除**:成本归一化下的维护叙事;收缩为"一次性深度分析"工具;删除跨会话方向 |
| stateful 与 stateless 均无法检出注入(Recall≈0) | 实验无效(任务不可见/过难) | **不删除方向,修实验**(注入可见性或任务措辞),重跑一次;再失败 → 按 H2 失败处理 |
| Cognition Diff 机械真值噪声 >20% | 工具失败 | 降级为 evaluator 人工判定(不删除 H2 本身) |
| 任何系统性边界违规(写入/证书 DEGRADED) | 实验无效 | 停步修实验,不修 Researcher |

**停止/降级触发(与 principal-verdict 一致,写死)**:

- **H2 失败(双仓库确认)→ 降级**:承认"Project Cognition Layer"定位不成立;保留"证据-backed 只读分析模式"价值(证据纪律/风险地图/决策备忘录/只读安全),删除 research-state 图机制与所有时间维度计划;记录为反例资产。
- **H2 成立 → 继续投入**:按 v0.9 路线(structured capsule + freshness gate)推进。
- **本实验不设第二轮预算**:一次裁决。

## 最终判断:继续 / 降级 / 停止

### 判断:继续(仅限 v0.8-alpha 的最小验证,一次性)

**理由(证伪导向,不默认继续)**:

1. **门槛条件满足**:research-state 引擎合格(单 reducer、局部失效代码正确),缺的是结构(指纹/关系/freshness)而非引擎 —— v0.8-alpha 的三工件(State Export / Diff / Handoff)全部是 host 侧格式转换与实验工具,**不触碰任何禁止项**(pipeline、prompt、agent 能力、memory 系统、benchmark 扩展)。
2. **假设未被证伪,也从未被测试**:实证 invalidate=0 / importState=0 —— 认知层的独有机制在全部历史实验中零激活。"停止"需要假设已证伪;"降级"需要失败已发生。当前两者都不成立,唯一理性的动作是**一次可裁决的测试**。
3. **成本与风险可控**:导出器(1–2 天)+ Diff(2–3 天)+ 单实验(12×2 sessions)。无第二轮预算承诺。
4. **不是"为了证明而继续"**:Part 4 失败标准已写死删除清单;若 H2 失败,降级路径明确,不会"加码续命"。

**反对继续的核心理由(已权衡)**:AI 模型进步可能在实验期间继续吞噬增量面(Part 3 的 stateless 对照组会如实显示);若 stateless 已足够强,实验会快速给出 H2 失败 —— **这正是实验存在的意义,而不是反对它的理由**。

### 若选择降级(备选,当前不采用)

只有当"不再愿意承担一次实验成本"时才选:立即承认"认知层未证明",降级为只读分析模式(保留 Part 4 中列出的保留项),删除全部时间维度计划。**但这是在零证据下放弃一个从未被测试的假设 —— 不符合证伪纪律,故不推荐。**

### 若选择停止(当前无依据)

停止需要"假设已证伪"或"方向已无价值";两者均无证据。**停止 = 逃避裁决,而非裁决。**

---

## 结论(一句话)

**v0.8-alpha 值得开始,但只值得开始它的最小形态:host 侧 Cognition State 导出器 + Cognition Diff + 单次 H2 状态继承实验;门槛(引擎合格、结构缺失可补、禁令零触碰)已满足;失败标准与删除清单已写死;若 H2 无增益则降级,不设第二轮。**
