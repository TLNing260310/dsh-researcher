## Root cause and next protocol

v1.8 correctly returned state derived after the current mutation call. On the final `complete_goal_attempt`, that response exposed candidate `decision=DONE`. Official Flash treated it as completion and ended the turn, even though the architecture and prompt reserve terminal application for `request_goal_decision` and the host never called `ctx.goals.complete`.

Protocol v1.9 removes `decision` from every mutation-tool response. Mutations return current progress and diagnostics only; completing an attempt or reporting a blocker explicitly directs the model to call `request_goal_decision`. Durable replay and the formal host terminal authority are unchanged. v1.8 artifacts and score are not migrated or rescored.
