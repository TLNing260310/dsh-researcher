## (5) Risk Map

**R1 — Behavioral regression: silent acceptance of excess arguments** *(Known, high)*. Every path that reaches `_processArguments` with extra operands (action handlers, legacy `command:<name>` listeners, leaf commands) now runs silently; the extras are dropped from `processedArgs` without any signal (`lib/command.js:1447-1470`). User-visible harm: typos and misused CLIs do the wrong thing quietly instead of failing with commander's canonical error — the exact failure mode v13 removed.

**R2 — Comment trust trap** *(Known, high for review integrity)*. The marker at `lib/command.js:1750` asserts "excess operands are rejected at parseOptions exit before dispatch" — **false**; the exit (1894-1897) has no check. A reviewer or AI agent that greps call sites and reads comments will conclude the check moved; only reading `parseOptions`' body reveals the truth. The mutation is engineered to survive comment-level review.

**R3 — Inert public API** *(Known, medium)*. `allowExcessArguments()` (848) still validates/sets `_allowExcessArguments`, but the flag is read only inside the dead `_excessArguments` (2149). Programs calling `allowExcessArguments(true)` and relying on the default error are indistinguishable; `allowExcessArguments(false)` is a silent no-op.

**R4 — Dead code with no lint tripwire** *(Known, low-medium)*. `_excessArguments` (2148) is never called; the `if` block at 1417-1420 is empty. ESLint will not flag either: `no-empty` exempts comment-only blocks, and `no-unused-vars` does not flag class methods (`eslint.config.js:51-52`). Only the test suite catches it.

**R5 — Detection by CI** *(Known, mitigating)*. `npm test` fails (see §6), so the mutation cannot ship through the project's own pipeline — containment exists *if* tests run.

**R6 — Doc drift** *(Known, medium)*. `Readme.md:696-698` ("Any unknown options, missing arguments, or excess arguments will be reported as an error"), `Readme.md:1021`, and `CHANGELOG.md:96` now contradict the code.

**R7 — Corpus integrity** *(Investigate, medium)*. `kind: internal_architecture` describes the target surface (internal machinery, public API untouched), but if the corpus semantics imply *behavior preservation*, MUT-04 is a mislabeled specimen: the observable change is a deletion with a false move-comment. Sibling mutations MUT-01/02/03 similarly alter behavior in their areas — consistent with "kind = target surface", which is the charitable and likely reading (C43, confidence 0.8).
