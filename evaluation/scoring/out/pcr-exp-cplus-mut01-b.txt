## 2. Architecture Map

Unchanged from prior model (C06, Known, 0.9) — verified anchors this session:

- **Core**: `Command extends EventEmitter` (lib/command.js:1); option values flow through `option:`/`optionEnv:` events (720–726, 1787–1984) with per-value source tracking (default/env/cli/implied/config).
- **Parse pipeline**: `parse()`/`parseAsync()` → `_prepareForParse()` (first call `saveStateBeforeParse()`, later calls `restoreStateBeforeParse()` — **the mutated function**) → `_prepareUserArgs()` (node/user/electron/eval origins, 1001–1055) → `_parseCommand()` recursive dispatch (1550) → single-pass `parseOptions()` state machine splitting operands/unknown (1748–1895) with negative-number disambiguation (1757).
- **State restore contract (v13+, CHANGELOG.md:85)**: repeated `.parse()` is supported by saving/restoring `_name`, `_optionValues`, `_optionValueSources`, `args`, `processedArgs`, `rawArgs` (1141–1174) — *unless* `storeOptionsAsProperties` is enabled, in which case upstream **throws** rather than attempt a restore. **MUT-01 replaces that throw** (1159–1161).
- **Help system**: extensible `Help` class with style*/format* methods, `configureHelp`/`configureOutput`, help groups (14.0.0), color conventions via `useColor()` (2752–2774, color off by default) (C07, Known, 0.9).
- **Executable subcommands**: `child_process.spawn`, extension probing `.js/.ts/.tsx/.mjs/.cjs`, signal forwarding, inspector-port increment, Windows ENOENT/EACCES handling (1202–1346; C08, Known, 0.9).
- **Packaging**: `index.js` facade; `exports` map with CJS/ESM branches + per-branch types (package.json:45–61); hand-maintained `typings/index.d.ts` (1113 lines) + `typings/esm.d.mts`; JSDoc type-checked via `tsc -p tsconfig.js.json`; tsd type tests (C09, Known, 0.9).
- **Quality gates**: jest (111 test files), eslint/prettier, tsd/tsc, CodeQL; CI matrix 20/22/24 × 3 OS (C04, Known, 0.95).

## 4. Design Decisions

All prior decisions hold (C15 partially; verified this session):

- **Zero runtime dependencies** — deliberate constraint; color handled by convention checks in `useColor()` rather than a dep (C03).
- **EventEmitter parse pipeline** — public custom-listener API, kept deliberately (C15).
- **`process.exit` control flow** — documented, with `exitOverride` escape hatch (C15).
- **ESM wrapper + dual typings** — avoids the dual-package hazard without a build step (C15).
- **Strict-by-default errors with opt-outs** — `allowUnknownOption`/`allowExcessArguments`/negative-number handling (C05).
- **Repeated-parse support via state save/restore** (13.0.0, #2299) with the `storeOptionsAsProperties` incompatibility enforced by a hard throw — **this is the decision MUT-01 violates**.
- **Compat-window policy** (docs/release-policy.md): semver; majors ~6 months; current line gets everything, previous major security-only for 12 months; 13.x EOL 2026-05-18 (now past; 14.x sole line).

**Impact chain** (C16, Known, 0.9):

The convention existed for a reason (restoring state with properties is unsafe: properties can't be reverted, hence the throw); that reason still holds.
